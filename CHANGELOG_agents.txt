  - Calculates anomaly scores using statistical analysis

- **Immune Engine** (`agent/src/core/immune_engine.hpp/.cpp`):

  - Supports multiple threat types and severity levels

- **Main Application** (`agent/src/main.cpp`):

### Technical Features Implemented
- **Biological Immune System Inspiration**:
  - Self/non-self recognition through behavioral profiling
  - Adaptive learning and memory formation
  - Threat detection and coordinated response
  - Collaborative intelligence sharing
  
- **Statistical Anomaly Detection**:
  - Z-score based numerical analysis
  - Pattern frequency analysis for network and file access
  - Configurable adaptation rates and thresholds
  
- **Automatic Response System**:
  - Configurable severity-based response thresholds

  - Atomic flags for safe shutdown
